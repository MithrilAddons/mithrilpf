Dungeon tracking is more reliable, and the Curator screen handles the daily reset cleanly.

**Changes**
- A party member typing "EXTRA STATS" in chat no longer ends your run's tracking. Only Hypixel's own end-of-run line does.
- If a run or setting can't be saved, tracking keeps running and the next save tries again, with a message in chat. Previously one failed save turned tracking off until you restarted.
- When a new Curator item arrives after you've finished a round, the **Load new item** button no longer covers your result.

**Updating**
Open `/mpf → Updates`, enable **Include pre-releases**, then select **Check now**. Once the update is ready, quit Minecraft normally and wait a few seconds before relaunching.
