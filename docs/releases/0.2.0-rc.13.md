New solo-clear replays distinguish teleport abilities and show the route taken through the dungeon.

**Changes**
- Records Etherwarp, Instant Transmission, Wither Impact, and other or mixed teleports through 300 score.
- The linked replay shows colored teleport markers, a full-route toggle, and run and room teleport totals. Grouped chains are counted, with four or more shown as `4+`.
- Older recordings show approximate teleport jumps. Passes shorter than one second no longer inflate visit counts; recorded room times are preserved.

**Updating**
Open `/mpf → Updates`, enable **Include pre-releases**, then select **Check now**. Once the update is ready, quit Minecraft normally and wait a few seconds before relaunching.

Start a fresh run after updating to record teleport types. Markers use sampled positions, and grouped teleports can combine different abilities.
