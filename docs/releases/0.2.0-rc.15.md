MithrilPF now asks before installing any update, and can add a missing required mod for you.

**Changes**
- When a new version is available, a window on the title screen shows its notes with **Install on exit**, **Remind me later**, **Skip this version**, **View on GitHub** and **View on Modrinth**. Nothing is downloaded until you choose **Install on exit**.
- If an update needs a mod you don't have, such as Hypixel Mod API, the window offers to install it from Modrinth together with the update. It never replaces or updates mods you already have.
- New installs are asked once whether to check for updates. The setting is now called **Check for updates on launch**, and `/mpf → Settings` has a **Review update** button.

**Updating**
Open `/mpf → Updates`, enable **Include pre-releases**, then select **Check now**. Once the update is ready, quit Minecraft normally and wait a few seconds before relaunching.

This update still installs the way previous versions did; the new window applies to later updates.
