Solo-clear PB syncing now recovers from brief connection failures during a run.

**Changes**
- Retries interrupted live PB updates, including the final update at 300 score.
- Recovers lost server replies without creating duplicate records or maps.

**Updating**
Open `/mpf → Updates`, enable **Include pre-releases**, then select **Check now**. Once the update is ready, quit Minecraft normally and wait a few seconds before relaunching.

Start a fresh run after updating. Previously interrupted runs cannot be recovered as verified PBs; their local PBs remain saved.
